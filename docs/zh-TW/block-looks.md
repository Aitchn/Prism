# 大量方塊外觀

一個 Mod 可以有任意多種自訂方塊外觀。Java 版玩家只需要資源包，客戶端不用安裝其他東西。（*外觀*指方塊某個變體朝向某個方向的樣子。）

## 外觀怎麼畫

Prism 每次開機都依目前註冊的內容，為每個外觀決定其中一種呈現方式（世界裡不存任何外觀，所以 Mod 可以隨意新增或移除方塊）：

- **借用的原版狀態**（S 層）。共 931 個原版方塊狀態，資源包可以替換它們的模型，因為這些方塊的真實方塊都能改以另一個外觀完全相同的
  狀態顯示：音符盒（799）、絆線（64）、標靶（15）、發射器與投擲器（各 6）、杉木與白樺樹葉（各 13）、甘蔗（15）。
  這一層最快：方塊就是方塊狀態，沒有實體。這些種類的原版方塊會以對應的普通兄弟狀態送給玩家，所以玩家放的音符盒看起來還是音符盒。
- **顯示層**（D 層），用於超出上述數量的外觀。對客戶端來說方塊是一個隱形的外殼（碰撞、是否遮擋鄰居、音效都正確），
  附近每位玩家會收到繪製模型的物品顯示實體，每個可見的面一個。伺服器上不會生成任何實體：這些實體只存在於
  `blocks.display.view-distance` 個區塊內玩家的封包裡。

外觀會先取同一**類別**的借用狀態，用完才改走顯示層。類別由碰撞（實心或無）、是否遮擋鄰居、以及音效組組成。
例如會遮擋鄰居、聽起來像木頭的實心方塊，與可穿過的方塊是不同類別。

## 元件

```yaml
components:
  prism:render: auto        # auto（預設）、state 或 display
  prism:surface:
    sound: glass            # wood、stone、gravel、grass、sand、snow、wool、metal、glass、bone、slime、netherrack、deepslate、copper
    occludes: false         # 是否遮擋鄰居方塊的面
```

- `prism:render: auto`：還有借用狀態就用，用完改走顯示層。
- `state`：要求借用狀態；沒有時仍可運作，日誌會提示（`PRISM_LOOK_WARNING`）。
- `display`：一律走顯示層。適合不該佔用那 931 個狀態的方塊。
- `prism:surface` 用來設定音效組，以及像玻璃這種不遮擋鄰居的方塊。可穿過的方塊（`prism:passable`）本來就是「無碰撞、不遮擋」。

實心方塊的預設類別是實心、遮擋、木頭音效；`prism:surface` 可以改，`prism:passable` 則使它可穿過。

## 挖掘

生存模式下，玩家挖自訂方塊的時間依 `prism:mining` 而定：玩家開始挖時，Prism 只針對這一次挖掘調整客戶端的破壞速度，停止後就移除。
可穿過的方塊和以前一樣瞬間破壞。

## 設定（`config.yml`）

| 設定 | 預設 | 意義 |
|---|---|---|
| `blocks.display.view-distance` | `8` | 玩家周圍會收到顯示實體的區塊數；`0` 表示客戶端有的所有區塊。 |
| `blocks.display.view-range` | `1.0` | 實體的可視範圍倍率。 |
| `blocks.display.solid-shells` | `false` | 實心顯示方塊改用不透明的音符盒外殼。除非已在客戶端確認，否則請維持關閉。 |

## 限制

- 顯示層方塊每位觀看者都要付出實體成本：每個方塊最多六個，只限上限範圍內的區塊。大型建築請只對重要的方塊使用顯示層，或調低距離。
- 實心的顯示層方塊，對客戶端是一個不遮擋鄰居面、聽起來像草的方塊（除非啟用音符盒外殼）。顯示層本身會略過被其他實心顯示方塊擋住的面。
- Geyser 在同一台伺服器時，基岩版玩家會把每個外觀都看成真正的自訂方塊（`bedrock.synthetic-blocks`，ADR-0024；見 `bedrock.md`）。否則他們只看得到借用的音符盒與絆線外觀，顯示層方塊對他們是隱形的：若方塊在那時必須在基岩版可見，請設 `prism:render: state`，並讓這類方塊的數量保持在借用狀態的數量以內。
- 未安裝的 Mod 的方塊沒有外觀，玩家看到的是普通載體。

設計、替代方案與尚未在真實客戶端驗證的部分，請見
[ADR-0023](https://github.com/Aitchn/Prism/blob/main/docs/adr/0023-look-pool-and-display-layer.md)。
